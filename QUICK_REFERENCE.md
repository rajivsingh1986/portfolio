### 🚀 Deploy (Choose 1)

#### Option A: Vercel (Recommended) ⭐
```bash
# 1. Git setup
cd d:\codex\portfolio
git init
git add .
git commit -m "Portfolio"
git branch -M main
git remote add origin https://github.com/USERNAME/portfolio
git push -u origin main

# 2. Go to vercel.com/new
# 3. Import your repo
# 4. Click Deploy
# 5. Get live URL instantly!
```

#### Option B: Netlify
```
1. Go to netlify.com
2. Click "New site from Git"
3. Select your repo
4. Auto-deploys
5. Get live URL!
```

#### Option C: GitHub Pages
```
1. Create repo: USERNAME.github.io
2. Push portfolio files
3. Site at: https://USERNAME.github.io
```
